# Build What Moves India

Hackathon project for Build What Moves India.

## Project

A citizen-first driving licence journey experience that simplifies the
Learner's Licence → Driving Licence process.

## Stack

- Frontend: React + TypeScript
- Backend: ASP.NET Core
- Database: SQLite
- AI: OpenAI API

## Structure

- `frontend/` — React application
- `backend/` — ASP.NET Core API
- `docs/` — Architecture and product documentation
- `data/` — Knowledge base and synthetic government data
